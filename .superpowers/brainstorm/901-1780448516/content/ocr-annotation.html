OCR 模型选型

为什么不用现成的 OCR？

Tesseract / ML Kit 通用 OCR 对电影字幕场景效果不佳：字幕字体多变、有描边阴影、背景复杂（视频画面）。 自训练模型可以针对字幕场景优化，同时通过蒸馏/量化做到极小体积。

模型架构：CRNN
  • CNN 提取视觉特征
  • RNN/LSTM 序列建模
  • CTC 解码输出文本
  • 成熟稳定，推理快
输入 / 输出
  • 输入：字幕区域裁剪图 (H×W×3)
  • 输出：英文字母 + 数字 + 标点
  • 字符集：A-Z, a-z, 0-9, .,!?-'""
  • 不区分大小写（或两种都支持）
体积目标
  • 训练后：~5-10MB
  • 量化后：~2-5MB
  • 推理速度：<50ms
  • 部署格式：TFLite / ONNX
