字幕处理管线

导入字幕 → 解析 → llama 预处理 → 缓存 → 运行时匹配

整体处理流程

1
导入 & 解析
支持 SRT / ASS / VTT / SUB 格式，自动检测编码（UTF-8 / GBK / Latin-1），统一解析为内部结构：
[索引, 开始时间, 结束时间, 文本]
2
文本规范化
去除 ASS 样式标签、HTML 标签 → 统一换行符 → 合并断句 → 去除特效字幕（歌词等）→ 生成干净的纯文本时间轴
3
llama 预处理（后台异步）
每句字幕送 llama 批量分析，提取：
难词标记 + 等级 词根词缀拆解 习语/俚语识别 中文释义 整句翻译 语法结构
4
用户词库融合
将 llama 标记的难词与用户历史查词记录交叉比对：查过的词 → 降低难度等级，多次跳过的词 → 标记为已掌握，首次出现的词 → 保持 llama 标记等级
5
缓存写入
所有分析结果序列化到本地 SQLite 数据库，按电影/字幕文件组织。后续播放无需重新分析。用户词库独立存储，跨电影共享。
